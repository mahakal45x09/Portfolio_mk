## 🛠️ Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mahakal45x09/Portfolio_mk.git
   cd Portfolio_mk
   ```

2. **Install dependencies**:
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
